AI File Reader

Let web-based AI chatbots read local files like an IDE.

Install

1. In Chrome, open chrome://extensions, enable Developer mode, click “Load unpacked,” and select the extension folder.
2. (Optional) Install the native service: double-click 安装本地服务.bat in the project root and paste the extension ID when prompted.
3. Restart Chrome and open any supported AI site.

Usage

A 📁 button appears in the bottom-right corner of the page (shortcut: Ctrl+Shift+F):

File treeClick 📁 to open the sidebar, browse folders, and click a file to insert it into the chat input.
@ commandType @filename or @foldername in the chat input, then choose an item from the list.

Two modes

Native service mode (recommended): fully automatic after installation. Requires Node.js.

Browser mode: no installation required. Open the sidebar and choose a folder. Authorization is required again after restarting the browser.

Supported sites

  • Qwen (chat.qwen.ai)
  • ChatGPT (chatgpt.com)
  • Gemini (gemini.google.com)
  • Claude (claude.ai)

Keyboard shortcuts

  • Ctrl+Shift+F — Open or close the file panel
  • @ — Start a file search in the chat input
  • ↑ ↓ — Move through search results
  • Enter or Tab — Select a file
  • Esc — Close search

Uninstall

Extension: remove it from chrome://extensions.

Native service: double-click 卸载本地服务.bat.
